# プライバシーポリシー — GitHub Bulk Cloner

最終更新: 2026-11-23

GitHub Bulk Cloner（以下「本拡張」）のプライバシーポリシーです。

## 収集する情報

本拡張は、いかなる個人情報も収集・送信しません。

- 解析ツールを組み込んでいません
- 外部サーバーへデータを送信しません
- アカウント情報を取得しません

## 取り扱うデータ

本拡張は、機能の提供に必要な次のデータだけを扱います。

| データ | 保存先 | 用途 |
| --- | --- | --- |
| 保存先フォルダのパス | ブラウザ内（`chrome.storage.local`） | clone 先の指定 |
| フォルダ構成の設定 | ブラウザ内（`chrome.storage.local`） | 保存先の形式の記憶 |
| 選択したリポジトリ名 | ローカルのネイティブホスト | `git clone` の実行 |

いずれも**端末内で完結**し、外部へ送信しません。保存先の設定はブラウザの同期対象外（ローカルのみ）です。

## 権限と用途

| 権限 | 用途 |
| --- | --- |
| `storage` | 保存先フォルダなどの設定を保持するため |
| `nativeMessaging` | ローカルのネイティブホストと通信し、`git clone` を実行するため |
| `tabs` | ポップアップから現在のタブの選択状態を取得するため |
| `host_permissions: https://github.com/*` | リポジトリ一覧にチェックボックスを表示するため |

本拡張は上記の用途以外に権限を使用しません。

## ネイティブホストについて

本拡張は、端末上で動作するネイティブホスト（Go 製の実行ファイル）と連携します。ネイティブホストは次の処理のみを行います。

- 受け取った `owner/repo` を検証する
- ローカルの `git` または `gh` を実行して clone する
- 結果を拡張へ返す

ネイティブホストは外部と通信しません。`git` および `gh` の通信は、それらツールが GitHub に対して行うものであり、本拡張が内容を取得・保存することはありません。

## 認証情報

本拡張は、アクセストークンやパスワードを受け取りません。GitHub への認証は、端末に設定済みの Git Credential Manager または GitHub CLI（`gh`）に委ねます。

## 第三者提供

行いません。

## データの削除

ブラウザの拡張機能ページから本拡張を削除すると、保存された設定（`chrome.storage.local`）も削除されます。clone したリポジトリは端末上の通常のフォルダであり、本拡張の削除では消えません。不要な場合は手動で削除してください。

ネイティブホストの削除は `installer\setup.ps1 -Uninstall` で行います。
